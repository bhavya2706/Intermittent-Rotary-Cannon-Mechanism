# Intermittent Rotary Cannon Feed System

**Author:** Bhavya Khandelwal  
**Institution:** Department of Mechanical Engineering, IIT Guwahati  

## Project Overview
This repository contains the kinematic design, 3D CAD models, and engineering blueprints for an intermittent rotary cannon feed system. The mechanism adapts a 4-slot Geneva drive to translate continuous motor rotation into precise, mathematically timed stop-and-go indexing.

## Key Engineering Features
* **Kinematic Synchronization:** Designed around a 75mm center-to-center distance with a 53mm offset pin, enabling an exact 90-degree index per cycle.
* **Dwell Phase Stabilization:** Integrates a 270° locking disk to completely freeze the barrel assembly during the firing phase, ensuring zero-gap alignment over the ammunition feed chute.
* **Design for Manufacturing (DFM):** 
  * Features a lightweight, scalloped muzzle clamp to mitigate barrel whip at high rotational speeds.
  * Includes base-integrated motor housing and chamfered structural edges for physical fabrication feasibility.
